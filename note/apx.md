- **Avg. Mean**：把同一題庫內該競爭算法的 `Mean` 欄位取平均。
- **Avg. PDev**：把同一題庫內該競爭算法的 `PDev` 欄位取平均。
- `—`：原文沒有提供該算法在該題庫的結果，或 `Mean` 欄位是 `-`。
- **CB 已拆成 cb1～cb6**。

原文 Table A2 的格式是 `Max / Mean / PDev / Rank`，且明確標示 `-` 為未提供資料；Weish 題庫多數文獻競爭算法只提供 `Max / - / PDev / Rank`，所以 Weish 的 `Avg. Mean` 無法彙總，只能彙總 `Avg. PDev`。
