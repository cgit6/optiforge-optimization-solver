## 預處理

### SimulatorBundle 和 Simulator 物件的調整想法

在開始搭建 `cil.exp` 模組之前目前的系統需要針對"具備多算法多參數組合模擬" 進行調整與重構，目前 `SimulatorBundle` 物件只能存 1 組題庫(多題目) 多組算法(solver) 和 1 組對應的算法參數設定。如果是跑 `cil.run` 通常我只需要看到 1 組題庫(多題目) 的 1 個算法下的 1 個參數組合結果(結果包含求解結果)。但是如果是 `cli.exp` 我會需要的是 多題庫(多題目) 多算法多參數組合的模擬結果。我希望 SimulatorBundle 和 Simulator 可以有能力模擬 1 組題庫(多題目)、多算法、多參數組合。 當 `cil.run` 執行模擬的時候 僅創建一組 SimulatorBundle 和 Simulator 進行模擬。當 `cli.exp` 執行模擬時依序創建多組 SimulatorBundle 和 Simulator 用於模擬算法和參數求解問題的結果(依照 `exp_cfg.yaml` 的 `dataset_settings` 依序創建 SimulatorBundle)

[問題]`SimulationBundle` 物件的 `ExperimentSpec` 物件是否支持改設定? 如果支持了 `cil.exp` 可以省去重複造物件的資源只需要改 `ExperimentSpec.seed` 就可以給下一個 seed 的實驗作使用(SHM 可以重複利用) 應該是不行，這樣會改變系統的可重現性。因此 `cil.exp` 的流程還是以跑一次題庫就創建一份新的 `SimulationBundle` 為方案。

`stat` 模組有問題，如果現在 executeSimulator 中執行完模擬後返回的結果 simulator_result 利用這個結果來計算模擬的統計結果是會把所有的算法&參數組合模擬結果混在一起進行計算? 我需要的是將算法&參數分開處理的統計結果，舉例如下:

```
在一次實驗中，進行以下統計
算法 A 第 1 組算法參數模擬題庫 W 的統計結果
算法 A 第 2 組算法參數模擬題庫 W 的統計結果
算法 B 第 1 組算法參數模擬題庫 W 的統計結果
算法 B 第 2 組算法參數模擬題庫 W 的統計結果
```

`show` 現在輸出的架構也有問題，一次實驗中(執行 `cil.run`) 可能會進行 多算法、多參數組合的模擬並對每一個組合進行統計分析，最後把每一個組合的模擬結果與統計分析結果存進對應的資料夾中。如果創建了一次的實驗中(執行一次 `cil/run`) 假設有 2 個算法(A、B)每個算法各兩組參數組合(1、2)期望的存放方式如下:

`cil.run` 的命令參數 `--output` 其實可以不用了。統一都存在 `output` 中，開一次實驗就用 `experiment-id` 當作 output 下的 folder name 就好了。

`cil.run` 的命令參數 `--param-set-index` 如果有填就指定

[問題] 如果跑多算法選 0 全部算法都選第一組參數很奇怪。我想看算法 A 的第一組參數不代表我想看算法 B 的第一組參數阿。
[方案] 不要判斷要跑哪一組算法參數，跑全部的算法參數組合，比如說模擬算法A、B 他們各有 7、3 組算法參數。那 Simulator 執行模擬的時候會把所有的參數組合都跑過一次。不會去判斷哪一組要跑哪一組不要跑。

`cil.run` 命令參數改名，現在的命令變數名稱都過長了，根據以下改名進行處理:

```
experiment-id -> experiment-name
problem-type -> type
dataset -> dataset
problems -> problems
solver -> solver
param-set-index -> param
repeat -> repeat
base-seed -> seed
output-dir -> 移除掉
execution-mode -> worker
```

以下幾個是必填，少填就報錯停止模擬
experiment-name
type
dataset
problems
solver

以下幾個選填如果沒填就使用預設參數
param -> 預設 -1 (跑全部參數)
repeat -> 預設 20
seed -> 預設 55688
worker -> 預設 1


然後現在在執行 `cil.run` 時如果 2 組算法，選 1 組參數組合來進行模擬(假設選第3組) 變成說選這兩個算法的 第三組設定進行模擬這件事我覺得也有問題，先不提如果 A 算法有 3 組參數設定 B 算法只有 1 組時的例外情況。
